# maxgfr.github.io

Maxime's personal site and CV, built with Zola (Anemone theme) and deployed to GitHub Pages by
`.github/workflows/deploy.yml`, which also renders the CV PDFs with
`.github/scripts/render-cv-pdf.mjs`. See `README.md` for the layout and local commands.

## Skills

- `skills/cv/SKILL.md` — generate, preview, and refine Maxime's CV PDFs and layout on the site.
  Use it only when the user asks for it (read the file and follow it).

Install it for your agent with `npx skills add .` (pick the agent, or `-a <agent>`).
